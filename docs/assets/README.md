# AgentConnector artwork

Generated with the built-in image generation tool. Resizing and PNG export preserve the generated artwork.

## Files

| File | Use |
| --- | --- |
| `agentconnector-cover.png` | README banner and GitHub social preview, 1280 × 640 |
| `agentconnector-icon.png` | Repository/project avatar, 512 × 512 |
| `agentconnector-nuget.png` | NuGet package icon, 128 × 128, packed as `icon.png` |
| `agentconnector-art.png` | Standalone repository illustration |

The icon uses violet and turquoise interlocking links on midnight navy. Use the square icon for avatars and the cover for repository sharing. Keep clear space around the mark; do not stretch it.

The cover is already referenced by the root README. The NuGet icon and README cover are included by the library project during packing. To activate the GitHub social preview, upload `agentconnector-cover.png` under repository Settings → Social preview → Edit. GitHub's repository file icon itself is controlled by GitHub; the square artwork is available for a project or organization avatar.

Export sizes follow [GitHub social preview guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview) and [NuGet icon guidance](https://learn.microsoft.com/en-us/nuget/reference/nuspec#icon). Both upload files are below 1 MB.
